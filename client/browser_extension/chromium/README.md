# PcTime 浏览器扩展

Chrome/Edge 116+：打开扩展管理页，启用开发者模式，选择「加载已解压的扩展程序」，加载本目录。

0.1.1 起：启动配套新版 PcTime，在设置中勾选「启用本地网站统计」。扩展自动连接并识别 Chrome/Edge，无需填写配对码或登记扩展 ID。点击扩展图标可查看状态或立即重连；桌面端稍后启动时也会定时重试。

从 0.1.0 升级时，先移除旧扩展，再重新加载本目录，使用新固定 ID。旧扩展的未确认队列/配置不迁移，请先保持旧版连接约 30 秒完成发送；桌面端已有统计不受影响。连接旧版桌面端的手动配对入口保留在「高级兼容设置」中。

仅连接 `ws://127.0.0.1:8909/pctime-browser`，插件没有远程上传接口。不申请页面内容、历史或 cookies 权限；忽略隐身页与非 HTTP(S) 页面。`alarms` 权限仅用于后台被回收后的重连。每 20 秒结算，未 ACK 事件持久化，最多保留 10 分钟/1000 条。桌面端离线时停止计时。桌面端仍接受旧连接路径，便于旧扩展平滑升级。

当前版本仅提供 host 采集，不提供完整 URL/标题模式。关闭桌面端网站统计可停止所有网站连接和采集；自动连接不会自动开启上传。
