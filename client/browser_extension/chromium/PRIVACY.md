# PcTime 网站使用记录：隐私说明

适用版本：Chromium 扩展 0.1.1 及配套桌面端。更新日期：2026-10-23。

新版在桌面端启用网站统计后自动连接，无需用户填写配对码。扩展即使尚未连接也会定时尝试访问本机桥接，但未获桌面端计时授权时不生成使用记录。自动连接不会自动开启桌面端统计或上传开关；旧版手动配对仅保留为兼容选项。

本说明描述当前代码的数据处理行为，供本地安装使用。正式商店发布前，发布者仍需补充运营主体、联系渠道及公开可访问的隐私说明地址。自建服务器的数据管理由服务器运营者负责。

## 收集什么

扩展通过浏览器标签页 API 读取活动标签页地址、窗口焦点和隐身状态，用于判断是否属于可计时的 HTTP/HTTPS 网页。完整地址仅短暂保存在扩展内存中以识别页面切换；当前版本不会将路径、查询参数、锚点、页面标题或 favicon 写入待发送队列或发送给桌面端。

启用并连接后，扩展向本机桌面端发送网站主机名（包含子域名，非默认端口会保留）、协议、片段起止时间、浏览器类型、随机配置实例标识、会话标识和事件标识。桌面端结合当前前台应用、空闲及暂停状态计算实际使用时长，保存在本机 SQLite 中。网站和应用时间线时长不会额外加到应用总时长中。

隐身页面、浏览器内部页面及非 HTTP/HTTPS 页面不计时。桌面端未连接或未授权计时的期间不累计网站时长。关闭网站统计后停止新增采集，已有数据不会自动删除。

## 数据去向与保留

扩展仅连接本机 `127.0.0.1:8909`，没有远程上传接口、广告或分析服务。随机配置实例标识、连接状态与待确认事件保存在浏览器本地扩展存储中，不使用浏览器同步存储；仅在用户配置旧版兼容连接时保存配对码。待确认事件在扩展运行时清理，最多保留最近 10 分钟内的 1000 条，并有约 1 MB 的序列化长度上限；扩展停用期间不会运行清理，恢复时先清理过期事件再发送。

桌面端网站片段、按日汇总及导出的 CSV 没有默认自动删除期限。用户可在桌面端清除网站记录；为防止重试消息恢复已删除数据，去重凭据和清除时间界限会保留。去重凭据超过一天后会在后续写入时清理，不包含网页地址。清除网站记录不会删除配对设置、已导出的 CSV、服务器历史数据或已经发送的邮件。

网站上传和软件时段上传各自默认关闭。用户开启对应开关后，可手动上传，或启用自动上传由桌面端定期发送。上传的网站数据包含主机名的每日总秒数、真实分时用量与起止时段；软件时段包含应用名称、真实使用起止时刻和每 15 分钟用量。请求也包含设备标识、主机名、平台和客户端版本。上传内容不包含完整网页地址、页面标题、应用窗口标题或程序路径。使用用户配置的 HTTP 或 HTTPS 服务端地址；HTTP 传输未加密，公网部署建议配置 HTTPS。

服务器可能将应用总时长、已授权的软件使用时段和网站图表发往用户设置的邮箱。服务器数据库、备份、收件箱的保留与删除由对应运营者或用户控制。客户端本地清除不代表服务器历史记录已全部删除；仍启用上传时，最近日期会按快照替换规则同步。需要完整删除服务器历史时应联系该服务器管理员。

## 权限用途与控制

- `tabs`：识别活动标签页地址、切换与关闭事件，不读取网页正文、表单、密码或 cookies。
- `storage`：保存本地连接配置、连接状态和未确认事件，以便重试。
- `alarms`：在后台被回收后唤醒并尝试重新连接桌面端。

可通过桌面端开关停止采集、停止任一数据集上传、添加忽略网站、清除本地网站记录及重置配对码。忽略列表影响之后的采集，不自动删除之前的记录。卸载扩展不删除桌面端、服务器、CSV 或邮箱中的数据。配对码与服务器 token 应视为凭据，不应公开。
